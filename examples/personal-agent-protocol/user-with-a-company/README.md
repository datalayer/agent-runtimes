# PAP User with a Company

The whole PAP journey between Ada's personal agent, Atlas, and one company,
Manzanita Outfitters, with both sides built from the PAP Python SDK and its
`demo` world: real ES256 keys, DPoP proofs and HTTP over ASGI in one
process, with no network and no model.

1. Atlas discovers Manzanita and opens a signed-out, pairwise Session.
2. Ada asks about her jacket order; Manzanita answers `sign_in_required`.
3. Ada approves Atlas on Manzanita's own page (Device Sign-In).
4. The same conversation continues, signed in; Manzanita proposes the
   exchange as an operation.
5. Ada approves exactly that revision; it is confirmed and performed once.
6. Ada disconnects Atlas: the Account Token is revoked.

The tool returns what each party saw: statuses, the operation's summary and
result as Manzanita wrote them. The user code, tokens, assertions, and proofs
stay with the host.

```bash
loop apps run examples/personal-agent-protocol/user-with-a-company/app.py
```

The **PAP User with a Company** UI example replays the same world step by
step, from a trace generated by [`../traces/generate.py`](../traces/generate.py).

See the [PAP company guide](https://personal-agent-protocol.datalayer.tech/guides/company/).
