# Loop REPL

The Loop, from a terminal: an interactive session with the same agents, the
same slash commands, and the same extensibility as the browser workspace —
built on the reactor's extensible REPL (`reactor.repl`), which supplies the
prompt loop, the slash menu with per-argument completion, the keyboard
shortcuts and the dispatch. What this package adds is what the loop is
*about*: the Pydantic AI session behind `respond`, the agent-runtimes server
underneath, and the built-in commands.

## The command

The `agent-runtimes` package provides an interactive assistant workflow via:

```bash
agent-runtimes chat
```

## The session

The interactive assistant experience is part of Agent Runtimes and runs through `agent-runtimes chat`.

### Quick Start

```bash
pip install "agent-runtimes[chat]"
agent-runtimes chat
```

This starts an interactive session with a background agent-runtimes server and the default valid agent spec.

### Interactive Mode

Launch without arguments to start a session with the terminal UX (TUX):

```bash
agent-runtimes chat
```

When started without `--agentspec-id`, the CLI lists available agent specs and lets you choose one interactively.

```bash
# Pick interactively
agent-runtimes chat

# Specify an agent spec
agent-runtimes chat --agentspec-id data-acquisition

# Disable codemode
agent-runtimes chat --agentspec-id data-acquisition --no-codemode
```

### Single-Query Mode

Pass a query to run one request and exit:

```bash
agent-runtimes chat "What is Python?"
agent-runtimes chat -a crawler "Search for AI trends"
```

### Connect to a Remote Server

Use the `connect` subcommand to attach to an existing server:

```bash
# AG-UI (HTTP/SSE) - default
agent-runtimes chat connect http://localhost:8000/api/v1/ag-ui/chat/

# ACP (WebSocket)
agent-runtimes chat connect ws://localhost:8000/api/v1/acp/ws/chat -t acp
```

### List Remote Agents

```bash
agent-runtimes chat agents
agent-runtimes chat agents --server https://agents.datalayer.ai
```

### Slash Commands

| Command | Shortcut | Description |
|---------|----------|-------------|
| `/help` | `Esc H` | Show available commands |
| `/status` | `Esc S` | Model, tokens, and connectivity |
| `/context` | `Esc X` | Visualize context usage grid |
| `/clear` | `Esc C` | Clear conversation history |
| `/tools` | `Esc T` | List available tools |
| `/mcp-servers` | `Esc M` | List MCP servers |
| `/skills` | `Esc K` | List available skills |
| `/codemode-toggle` | `Esc O` | Toggle codemode on/off |
| `/agents` | `Esc A` | List agents on the server |
| `/tools-last` | `Esc L` | Show tool calls from last response |
| `/context-export` | `Esc E` | Export context to CSV |
| `/exit` | `Esc Q` | Exit the interactive session |

The registry in `agent_runtimes/chat/commands/` carries more than the table —
`/models`, `/suggestions`, `/about`, and an **Open** group (`/browser`,
`/jupyter`, `/datalayer`, `/surface`, plus notebook and document variants)
whose members appear when their target is configured. `/help` lists exactly
what your session has.

### Banner and Animations

```bash

agent-runtimes chat --eggs
```

### Programmatic Usage

Import and customize the embedded assistant agent directly:

```python
from agent_runtimes.chat.cli import agent

@agent.tool()
def my_custom_tool(data: str) -> str:
	return f"Processed: {data}"

agent.to_cli_sync(prog_name="agent-runtimes chat")
```

## How it is built

The interactive CLI is built on Pydantic AI and Agent Runtimes.

### Key Components

- `agent_runtimes/chat/cli.py`: Typer commands, runtime process management, and transport wiring
- `agent_runtimes/chat/tux.py`: Rich terminal UX, slash command handling, and streaming rendering
- `agent_runtimes/chat/commands/`: slash command modules and registry
- `agent_runtimes/chat/banner.py`: brand output and animation helpers

### Runtime Flow

1. `agent-runtimes chat` resolves an agent spec (provided or interactive picker).
2. It starts an embedded `agent-runtimes serve` process.
3. It waits for `/health` then fetches `/health/startup`.
4. Interactive mode launches TUX and streams responses over AG-UI.
5. On exit or signal, child processes are terminated cleanly.

### Transport Support

- AG-UI (`HTTP/SSE`) is the default for local and remote interactive chat.
- ACP (`WebSocket`) is supported via `agent-runtimes chat connect -t acp`.

### Slash Command Registry

Slash commands are modularized in `agent_runtimes/chat/commands/` — one file
per command — and registered into the **reactor's** slash command registry
(`reactor.slash.SlashCommandRegistry`). The interactive machinery underneath
— the slash menu with per-argument completion, the keyboard shortcuts, the
dispatch and follow-up-prompt convention — is the reactor's extensible REPL
(`reactor.repl`), which knows nothing about agents; this terminal is its
largest consumer.

The registry is extensible from outside this repository: a distribution
advertising a plugin under the `loop.plugins` entry-point group has its
`provide_slash_commands(registry)` hook called, and its commands appear in
the menu beside the built-ins.

```toml
[project.entry-points."loop.plugins"]
my-package = "my_package.loop_plugin:plugin"
```

### Packaging

CLI-specific dependencies are defined in `agent-runtimes[chat]`:

```bash
pip install "agent-runtimes[chat]"
```

The primary user entry point is the `agent-runtimes chat` subcommand from the main `agent-runtimes` CLI.
