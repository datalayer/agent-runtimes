# UI Plugins and the catalog of visual components

A **UI plugin** is how an agent's answer becomes an interface rather than text: a
protocol the host renders — A2UI today; MCP Apps and MCP UI are listed and not enabled.
Each plugin hosts **the catalog of visual components** it renders (LOOP C-13): A2UI's
18 standard v0.9 components (`Text`, `Row`, `Card`, `Button`, `ChoicePicker`…) and
Datalayer's own six — `Table`, `Chart`, `FileUpload`, `Chat`, `Evidence` and `Form`.
Every one has a version and carries its properties as a JSON Schema of the catalog's
own — a standard one's named, required and chosen as A2UI's are; Datalayer's own with
what it can be bound to, the events it reports and a valid example.

The plugins are specs of [Agentspecs](./index.mdx) (`agentspecs/ui-plugins/*.yaml`).
Their fields, every component and how an Appspec's surface names one are documented
there: [UI Plugins](https://agentspecs.datalayer.tech/agents/ui-plugins) and
[the catalog of visual components](https://agentspecs.datalayer.tech/agents/ui-plugins/components).
This page is about the lookups Agent Runtimes generates from them.

## The generated lookups

`make specs` generates the plugins into one catalogue per language — do not edit them
by hand:

| | Python | TypeScript |
|---|---|---|
| Module | `agent_runtimes.specs.ui_plugins` | `src/specs/uiPlugins.ts` (`@datalayer/agent-runtimes/lib/specs/uiPlugins`, also re-exported from `@datalayer/agent-runtimes`) |
| The plugins, by id | `UI_PLUGIN_CATALOGUE` | `UI_PLUGIN_CATALOGUE` |
| One plugin | `get_ui_plugin(plugin_id)` | `getUIPlugin(pluginId)` |
| Every plugin | `list_ui_plugins()` | `listUIPlugins()` |
| The components, by the name a surface gives them | `COMPONENT_CATALOGUE` | `COMPONENT_CATALOGUE` |
| One component, or none | `get_component(name)` → `ComponentSpec \| None` | `getComponent(name)` → `ComponentSpec \| undefined` |
| Every component | `list_components()` | `listComponents()` |
| Types | `UIPluginSpec`, `ComponentSpec`, `ComponentBindingsSpec` (`agent_runtimes.types`) | `UIPluginSpec`, `ComponentSpec` (`src/types/agentspecs.ts`) |

`COMPONENT_CATALOGUE` holds the components of the **enabled** plugins only: a plugin
that is listed and not enabled contributes none, and a component no enabled plugin
renders is `None` / `undefined`.

A `ComponentSpec` says:

| Field | Meaning |
|---|---|
| `id` | The name a surface gives it (`Table`). |
| `name` | What a builder reads on the palette. |
| `description` | What it is for, in a sentence. |
| `category` | `text`, `input`, `action`, `data`, `conversation`, `media` or `layout`. |
| `emoji` | Its face on the palette. |
| `version` | Its version in the catalog: A2UI's standard ones `0.9.0`, Datalayer's own `1.0.0`. |
| `standard` | Named and drawn as its protocol says (A2UI's basic catalog). |
| `properties` | Its properties as a JSON Schema: what a builder sets — what the Canvas draws its properties form from, and what types its Python call. A value A2UI lets be bound (`{"path": …}`) is written here as the value itself. |
| `bindings` | For Datalayer's own: what it `shows` and what it `sends`. |
| `events` | What it reports. |
| `example` | A configuration of it, valid against `properties`. |

```python
from agent_runtimes.specs.ui_plugins import COMPONENT_CATALOGUE, get_component

table = get_component("Table")
table.properties["required"]       # ['columns']
table.bindings.shows, table.events  # (['rows'], ['select'])
get_component("Marquee")           # None: no enabled plugin renders it
len(COMPONENT_CATALOGUE)           # 24
```

```ts
import { getComponent, listComponents } from '@datalayer/agent-runtimes/lib/specs/uiPlugins';

const chart = getComponent('Chart');
chart?.properties; // its JSON Schema: kind, x, y, title, series
listComponents().filter(c => !c.standard).map(c => c.id);
// ['Table', 'Chart', 'FileUpload', 'Chat', 'Evidence', 'Form']
```

## Where they are read

- **The application checks** (`src/loop/apps/checks.ts`): `componentNamed` is
  `getComponent`, and `checkApp` says an application is not ready when its
  `interface.components`, or a node of its `surface`, names a component the catalog does
  not have — the same sentences as `app_problems` in Agentspecs.
- **Python** (`Application.component`, and `app.ui`, below): every component placed
  from Python is checked against its schema, a standard one too.
- **Forms** (LOOP C-16): `checkApp` refuses a `Form` whose `schema` is not an object of
  named fields, or that requires a field it does not ask (`formProblems`, agentspecs'
  `form_problems`); and when an action arrives, the runtime checks the values a `Form`
  sends with it against the same schema (`agent_runtimes.loop.apps.forms.form_values_refused`):
  refused, the session API answers 422 with the sentence —
  *“The quote” was sent what its fields refuse: seats: 0 is less than the minimum of 1.* —
  and the application's handler is not called.
- **Tests** hold the catalogue to the plugins (`agent_runtimes/tests/test_ui_plugin_components.py`):
  the component catalog is A2UI's own, every component has a version and a schema,
  Datalayer's carry an example their schema meets, and an unknown name is `None`.

## Typed calls from Python

The same generation writes every component as a typed call (LOOP C-15):
`SurfaceComponents` in `agent_runtimes.specs.ui_plugins`, which an application reaches
as `app.ui`. One method per component, named for it in snake case (`Table` → `table`,
`TextField` → `text_field`), whose keyword arguments are its properties, typed from its
JSON Schema — an enumeration a `Literal`, a required property without a default — and,
for Datalayer's own, its bindings; each may be bound instead (`{"path": …}`). An IDE
completes them, a type checker refuses a wrong value before the application runs, and
the call writes the node `app.component(id, component, **properties)` writes, checked
against the same schema:

```python
app.ui.column("root", children=["runs"])
app.ui.table("runs", columns=["model", "cost"], page_size=10, rows={"path": "/runs"})
app.ui.text("hello", text="Hello", variant="huge")  # refused: 'huge' is not one of h1…body
```

## How they are drawn

`datalayerCatalog` (`src/components/a2ui`, `@datalayer/agent-runtimes/lib/components/a2ui`)
is the A2UI catalog every Datalayer surface draws from — the decision surface,
`InlineSurface`, `A2uiView`, an application's page and the Studio's components page.
It holds A2UI's basic components **and a renderer for each of Datalayer's own six**
(LOOP C-18), under the basic catalog's id, with `visible_when` on every one.

Each renderer is made by `@a2ui/react`'s own `createComponentImplementation`, so it
binds and acts exactly as a basic component does. Its A2UI schema is built from the
catalog (`ownComponentSchema(id)`): every property its JSON Schema declares, typed as
it says; each name in `bindings.shows` and `bindings.sends` a binding — a
`{"path": …}` into the data model, or a value given in place; an `action`, written as a
Button's; and `weight`. The schema is strict: a key the catalog does not declare
refuses the tree. Sending is A2UI's path: the renderer writes what a person did where
its `sends` binding points, then dispatches its `action`, whose context reads that path.

| Component | Shows | Sends, then dispatches its action |
|---|---|---|
| `Table` | `rows`: a list of records, under `columns`, `page_size` at a time | `selected`: the row chosen by pointer or by Enter/Space, when `selectable` |
| `Chart` | `points`: a list of records, drawn with ECharts as a `bar`, `line`, `area` or `scatter` of `y` by `x`, a series per value of `series`; its numbers also as a table under *The numbers* | — |
| `FileUpload` | — | `files`: `[{name, type, size, data_url}]`, once each file is of a kind in `accept` and within `max_mb` |
| `Chat` | `messages`: `{role: 'user' \| 'assistant', text}` or `{role: 'tool', name, args, result}` (shown while `show_tools`), drawn by the chat's `ChatMessageList`; `welcome` and `starters` before the first | `message`: what is written in the composer, or a starter chosen |
| `Evidence` | `sources`: `{title, url, passage}`, the first `max_items` and the rest behind *more* | — (opening a source dispatches its action) |
| `Form` | `values`: the record the form starts from, its fields generated from `schema` with `@datalayer/primer-rjsf` | `values`: the form's values when it is valid and sent |

```json
{"id": "runs", "component": "Table", "columns": ["model", "cost"], "selectable": true,
 "rows": {"path": "/runs"}, "selected": {"path": "/chosen"},
 "action": {"event": {"name": "choose", "context": {"run": {"path": "/chosen"}}}}}
```

`DRAWN_OWN_COMPONENTS` (`lib/components/a2ui/datalayer/drawn`) lists them without
loading the renderers; the renderers' module refuses to load when it and the catalog
disagree, so a component added to the catalog without a renderer fails at once.

On an application's page, a chat publishes its conversation at `/messages` for a
`Chat` block, and a widget takes a `FileUpload`'s files at `/files` and hands a text
file's contents to its agent when it is run (`upload` runs it at once): see *An
application's page* on the Loop page.
